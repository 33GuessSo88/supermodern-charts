# supermodern-charts - legacy chart CDN

Public repo of chart images that the old Sierra Interactive pages of supermodern.ca load through
jsDelivr. Legacy since the site moved to Cloudflare (2026-10-20); nothing writes here since
2026-10-27, when the content engine that pushed charts was removed. It goes when Sierra goes.

- **Public:** everything committed here is on the internet. Aggregate charts only, never MLS rows,
  addresses or client data (the shared rules in `HQ/CLAUDE.md`).
- **No new work.** New charts belong to the website (`Website_Migration`). Do not delete or rename
  files: a live Sierra page may still link them.
- How it fits with the other projects: `HQ/SYSTEM_MAP.md`.
